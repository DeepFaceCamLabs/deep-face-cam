# Code of Conduct

This project is for building a safer, maintainable desktop face-swap tool. Be
direct, respectful, and specific when discussing code, design, and safety.

## Expected Behavior

- Use welcoming and inclusive language.
- Focus criticism on the work, not the person.
- Respect different skill levels and operating systems.
- Report security or misuse-enabling issues privately when disclosure would
increase harm.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Requests or contributions designed for fraud, impersonation, non-consensual
intimate imagery, targeted harassment, or evasion of consent and safety checks.
- Publishing private user media, secrets, model files with unclear rights, or
download links that violate upstream terms.

## Enforcement

Maintainers may edit, close, or remove issues, pull requests, discussions, and
comments that violate this code. Serious or repeated violations may result in a
ban from project spaces.
