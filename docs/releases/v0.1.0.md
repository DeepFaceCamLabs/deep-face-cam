# Deep Face Cam v0.1.0

This is the first source release of Deep Face Cam.

## Included

- Cross-platform Tauri desktop interface.
- React and TypeScript frontend.
- Bundled Python backend source.
- Model manifest and model download flow.
- macOS packaging scripts for local installer builds.
- Open-source project documents for contribution, security, privacy, model licensing, distribution, and responsible use.

## Distribution note

This GitHub release contains source code only. Public installer binaries are not attached here.

Installer builds may be distributed separately through the project website or supporter download page. When installers are published, release checksums should be generated and published with the installer artifacts.

## Model note

Face-swap and enhancement models are not committed to this repository. The app downloads required models with a user-visible prompt and stores them locally.

## Responsible use

Use this software only with appropriate consent and in ways that comply with local law and platform rules. See `docs/RESPONSIBLE_USE.md` and `docs/PRIVACY.md` for the project guidance.
